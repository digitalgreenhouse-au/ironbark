About

Ironbark reads your music where it is: the songs never leave this computer. The page carries a lock (a Content Security Policy) that stops it fetching or sending anything over the internet. Settings are kept in this browser only.

Bit-perfect playback isn't possible in a browser: the browser mixes every page's sound and hands it to the computer at its own rate. The desktop Ironbark plays bit-perfect and proves it. Here, Details shows what the browser does, and Check this file proves that a FLAC file itself decodes exactly.
